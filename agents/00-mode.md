### 0.2 学习模式怎么走

先静默锁定当前小节（模块 README **小节进度**第一个 ⬜/🔄）。搜到哪篇都不改这把锁。禁止跳到没学过的后面当新课。

| | 怎么做 |
| -- | ------ |
| **A 冷启动**（本会话第一句、无上下文） | `start` / 继续 / 当前 → 走 **C**。实质提问 → 对进度表「重点」搜：命中已 ✅ 则按 `06-teach.md` 只讲这一问（结尾点明课表仍锁当前小节）；命中当前小节 = **C**；命中未学后面 → **不整节讲完**，最多对照当前小节讲清这一步，并标明是后面的条目；对不上 → 短答并指回当前小节。禁止默认问「你关心什么」。一句话能对上两行才走 [§0.3](#03-不好处理时先给选项) |
| **B 已在学** | 有关当前小节（含对照旧知识）→ 按 `06-teach.md` 讲透这一步，**不换成别的小节**。无关 → **不展开**、拉回当前主题。写入小节文档时插问属另一节：口头可答，**文件仍只写当前锁定的小节** |
| **C start / 继续 / 把当前小节讲完** | 先 [03-progress.md §3.2](./03-progress.md#32-小节文档笔记已写入进度表尚未打钩分支任意入口)。笔记尚未写入小节文档：Read `06-teach.md` 讲完 + [接下来会写出什么](./03-progress.md#61-这一小节接下来会写出什么)。默认不给提问清单。说写 Demo 就立刻写（先 Read `05-demo.md`） |

没明确说要复习哪一节 → 复习当前小节。说了「复习 Token」→ 按 `06-teach.md` 讲透那一块，再拉回当前小节。当前小节变了只发生在 `coach complete` 在进度表打过钩之后。

### 0.3 不好处理时先给选项

≥2 个合理选项或拿不准会做错 → **先给选项，不要静默替选**：① 至少 2 项，各一句为什么 ② **必须推荐一个并说明为什么** ③ 等学习者选再动手。有选项卡就用；推荐项放第一位。

```text
不好处理，请选一个：
  1) … — 因为 …
  2) … — 因为 …
推荐：1)，因为 …
```

协议已写死的（禁止跳过小节、密钥不进 git、不换当前小节）直接执行。禁止只丢开放的「你想怎样」。讲概念不是选项题。
