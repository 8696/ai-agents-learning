```bash
cd apps

```

浏览器打开：http://127.0.0.1:50100/

端口：`50100`（yarn 脚本 inline `PORT=50100`；`lib/http/runtime-ctx.ts` `.default(50100)` 兜底）

## 数据流

```text
用户在页面写一句话（或点例句按钮）
    → 点「归类这句话」POST /api/classify
    → 服务端拼 messages：
        system = 四类记忆定义 + 短期/长期判定口径
        user   = 这句用户原话
    → 调协议 A 对话补全（response_format: json_object）
    → 解析模型返回的 JSON，校验字段（memoryType / term / reason）
    → 页面：
        ① 四个盒子（工作记忆 / 情景记忆 / 语义记忆 / 程序性记忆），命中的那一个高亮
        ② 判类结果：归入哪一类、短期还是长期、一句理由
        ③ 完整的模型请求（原始 request）
        ④ 完整的模型响应（原始 response）
        ⑤ 历史判类结果列表（可以连续判多句话，对照落进哪个盒子）
```

## 当前能做什么

- 输入任意一句话，或点四个例句按钮（分别期望落进四个不同的盒子）
- 看见真实发给模型的请求体和模型返回的原始响应，不是摘要
- 空句子 → 4xx；「演示后端 5xx」→ 另一条失败通道
- 本步不做跨会话存储、不做重启验证——只演示「同一句话该归进哪个盒子」这一件事
