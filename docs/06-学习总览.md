# 学习总览

24 个模块的**正文**在 [docs/学习模块/](./学习模块/README.md)：**一模块一文件夹**（`README.md` = 进度 + 验收；每小节一个 MD = 笔记）。本页只做两张总表：模块过没过完、五个项目交没交得出。

**一条路走下去。** 00 → 23。每个模块：先把小节进度从上到下勾完（外部；**每条小节 MD 要按模板写过**）→ 再本地验收 + 写 `{NN}-本地产出.md` → 才进下一模块。官方文档 → [资源清单](./05-资源清单.md)。

有代码的项目另有 **`README.md` + `LEARNING.md` 两份**（只这两份，随代码改写）。`coach status` / `start` / `next` 必须报出当前节奏。

## 怎么走

1. 按 00 → 23 打开 [学习模块](./学习模块/README.md) 对应文件夹的 `README.md`，扫 **小节进度** 里第一个 ⬜ / 🔄。
2. 该行是外部概念 → 节奏 = **外部学习**；该行是「本地产出」→ 节奏 = **本地产出**（对照同一 README **验收**）。
3. 这一格之前必须全是 ✅。外部没走完不写该模块代码（模块 01 的本地就是把 [本地产出](./学习模块/01-AI与LLM基础认知/11-本地产出.md) 写清楚）。

| 节奏 | 勾 ✅ | `coach next` |
| ---- | ----- | ------------ |
| 外部 | 能按「本条要能讲清」列讲清楚，且该条小节 MD 的 **过关自检**已覆盖该列（默认写满本对话） | 空壳未写入不准勾。勾该 README 小节进度这一条；链接写入「我的链接」；指向下一条。本模块外部全过 → 本页总表「外部」改 ✅ |
| 本地 | 该 README 验收过 + `{NN}-本地产出.md` 已按模板写过（有代码则 `LEARNING.md` 跟上） | 有代码则更新 `LEARNING.md`；勾「本地产出」+ 本页总表「本地」；进入下一模块第一条外部 |

看过的 URL 填进该模块 README「我的链接」（允许 `暂无链接`；**禁止**写「留在本对话学」等学习方式——来源写进该条小节 MD 的 `来源` 行，见 [AGENTS.md §7.1](../AGENTS.md#71-我的链接列)）。不要编网址。

`coach start` 外部必给出门包（[AGENTS.md §6.1](../AGENTS.md#61-外部学习出门包节奏外部时必出)）。

概念模块大约 2–4 小时；有本地代码的往往 4–8 小时（07 / 08 / 16 / 22 会更长）。先过小节进度，再按你自己的速度估。
