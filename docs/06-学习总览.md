# 学习总览

24 个模块的**正文**在 [docs/学习模块/](./学习模块/README.md)：**一模块一文件夹**（`README.md` = 进度 + 验收；每小节一个 MD = 笔记）。本页只做模块进度总表（外部 / 本地）。

**一条路走下去。** 00 → 23。每个模块：先把小节进度从上到下勾完（外部；**每条小节 MD 要按模板写过**）→ 再本地验收 + 写 `{NN}-本地产出.md` → 才进下一模块。官方文档 → [资源清单](./05-资源清单.md)。

有代码的模块另有 **`README.md` 一份**（只这一份，随代码改写）；`apps/{模块}/{小节}/` 子文件夹也是 `README.md` 一份。`coach status` / `start` / `next` 必须报出当前节奏。

## 怎么走

1. 按 00 → 23 打开 [学习模块](./学习模块/README.md) 对应文件夹的 `README.md`，扫 **小节进度** 里第一个 ⬜ / 🔄。
2. 该行是外部概念 → 节奏 = **外部学习**（条末可 Demo；按 [AGENTS.md §5.2](../AGENTS.md#52-小节-demo) 判断）；该行是「本地产出」→ 节奏 = **本地产出**（对照同一 README **验收收口**，不是从零灌代码）。
3. 这一格之前必须全是 ✅。外部条按条落 Demo（[AGENTS.md §5.2](../AGENTS.md#52-小节-demo)，判断结论可以是无 / 伪代码 / 可运行）；不要等最后一行才一次性灌代码。模块 01 的本地仍是把 [本地产出](./学习模块/01-AI与LLM基础认知/11-本地产出.md) 写清楚（笔记收口；已落的 Token 等 Demo 保留）。本地产出行 = 该模块验收**收口**。

| 节奏 | 勾 ✅ | `coach next` |
| ---- | ----- | ------------ |
| 外部 | 能按「本条要能讲清」列讲清楚，且该条小节 MD 的 **过关自检**已覆盖该列（默认写满本对话）；**且**本条 Demo 已按 [§5.2](../AGENTS.md#52-小节-demo) 判断 | 空壳未写入或 Demo 未判不准勾。勾该 README 小节进度这一条；链接写入「我的链接」；指向下一条。本模块外部全过 → 本页总表「外部」改 ✅ |
| 本地 | 该 README **验收收口**过 + `{NN}-本地产出.md` 已按模板写过（有代码则子文件夹 `README.md` 跟上）。前面外部条应按条落过对应 Demo，本行补缺口，不要从零灌全部代码 | 有代码则更新该子文件夹 `README.md`；勾「本地产出」+ 本页总表「本地」；进入下一模块第一条外部 |

看过的 URL 填进该模块 README「我的链接」（允许 `暂无链接`；**禁止**写「留在本对话学」等学习方式——来源写进该条小节 MD 的 `来源` 行，见 [AGENTS.md §7.1](../AGENTS.md#71-我的链接列)）。不要编网址。

`coach start` 外部默认讲完 + 告诉你本条要不要写 Demo（默认先不落；你说写就立刻写）。要出门学再说「出门包」（[AGENTS.md §6.1](../AGENTS.md#61-外部学习出门包点名才出)）。

概念模块大约 2–4 小时；有本地代码的往往 4–8 小时（07 / 08 / 16 / 22 会更长）。先过小节进度，再按你自己的速度估。
