# 自测题库（按模块归类）

> 用法：让 AI 助手「就这些题连续追问」或「考我模块 XX」。验收与勾选见 [docs/学习模块/](./学习模块/README.md)。
> 标准：能不看资料讲清楚，并且能举出自己 apps/ 里的实例。学完所有模块后，用 [4.8](#48-综合验收模块-23) 做全程收口。

## 4.0 环境准备（模块 00）

- API Key 应该放在哪？哪些地方绝对不能出现 Key？
