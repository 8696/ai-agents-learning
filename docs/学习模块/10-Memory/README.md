## 验收

> 本地节奏 / `coach next` 勾本地前对照本节。

**一句话目标**：理解 Agent 如何拥有跨会话的长期记忆。

**动手产出**：给 Agent 加长期用户记忆。

**验收标准**
- [ ] 区分并实现了短期记忆（本次会话）和长期记忆（跨会话持久化）
- [ ] 长期记忆有写入策略：什么信息值得记，什么不值得
- [ ] 长期记忆有检索策略：不是全量注入，而是按相关性召回
- [ ] 长期记忆有压缩或摘要：存的是提炼过的事实，不是把原始对话整段塞进去
- [ ] 实现了记忆的更新和冲突处理（用户说「我改用 Vue 了」要覆盖旧记忆）
- [ ] 记忆存储在真实数据库里，重启进程后仍在
- [ ] 有一个跨会话验证：新开会话时 Agent 记得我的偏好

**自测问题**：如何设计一个记忆系统？记忆和 RAG 的区别是什么？记忆冲突怎么解决？

**常见坑**：把所有历史消息都当作记忆存起来，检索时噪音巨大。记忆应该是**提炼过的事实**，不是原始日志。
