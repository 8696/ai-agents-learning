## 收口时补的（`coach next` 时发现缺口）

进入本地产出行时对照验收，发现 **2 项缺口**，当场补：

1. **非流式模式** — 加 `yarn dev --no-stream` flag 走一次性返回
   - 解析 argv 取 `--no-stream`（过滤掉再拼 userMessage）
   - `useStream=false` 时调 `chat.completions.create({ messages })`（不传 stream:true）
   - 一次性返回 `ChatCompletion`（含 `message.content` + `usage`），不走 3s 自动 abort（一次性返回没"中途"可言）
2. **估算成本** — 加 `MINIMAX_PRICE_PER_1K` env + `printUsageAndCost(usage)`
   - 公式：`cost = total_tokens / 1000 × MINIMAX_PRICE_PER_1K`
   - 单价 env 化（Zod `MINIMAX_PRICE_PER_1K`，默认 0.001 = MiniMax-M3 占位价）
   - 流式 + 非流式两条路径都打成本

详见 [LEARNING.md 与后续模块的衔接](../../../apps/01-chatgpt-mini/LEARNING.md#与后续模块的衔接) + [LEARNING.md 必答 5 问 Q7/Q8](../../../apps/01-chatgpt-mini/LEARNING.md#必须能答的-5-个问题)。

## 取舍

- **流式 vs 非流式默认走哪个**：默认流式（用户体验好，TTFT 短）；非流式靠 `--no-stream` 显式开。**取舍点**：流式优先，但成本可控 / 自动化 / 批量任务场景必须能用非流式
- **`MINIMAX_PRICE_PER_1K` 默认 0.001**：占位价；实际单价按 vendor 控制台填。**取舍**：精度 vs 配置成本——粗估够用就行，不要把全模型价目表塞 env
- **3 秒自动 abort 留在流式**：非流式不走（一次性返回没法中途取消）。**取舍**：模拟用户体验 vs 真实非流式场景——前者更贴近真实，后者更纯净
- **`printUsageAndCost` 收口补 vs 04-Rate-Limit 那条补**：放在本地产出，因为 04 那条「能讲清 Rate-Limit」就够了，「打印成本」是验收级而非 Rate-Limit 概念级

## 踩坑（本对话实际撞过的）

- **`yarn dev:server` 端口冲突**：多次跑没关进程，5176 / 3000 端口被占。`lsof -ti :5176 | xargs kill -9` 清掉
- **`NodeJS.HttpIncomingMessage` 类型不存在**：[`src/retry.ts`](../../../apps/01-chatgpt-mini/src/retry.ts) 用了 `NodeJS.HttpIncomingMessage["headers"]`，实际是 `IncomingMessage`（从 `node:http` import）
- **`RETRYABLE_STATUS` 声明但未使用**：第一次写分类时显式列了，代码只查 NON_RETRYABLE_STATUS；删了显式集合，注释写清"隐式可重试"
- **`result: T | string` 类型统一**：成功路径 body 是 `T`（流 / 非流对象），失败路径 body 是 `string`（错误信息）；`RequestFn<T>` 用 `body: T | string` + 成功时 `as T` 断言
- **`yarn dev --no-stream` 第一次跑没看到 retry 输出**：正常——单次请求没 429，attempts=1，`logRetry` 跳过；要看 retry 链路得在 burst 模式或真 API 撞限
- **真 API burst 没撞出 429**：MiniMax-M3 个人 Key RPM 配额宽裕；20 并发只占 ~2 RPS；要撞得 50+ 并发或换更小模型

## 过关自检（对照验收 6 条）

合上代码，必须能讲清：

1. **流式 vs 非流式差在哪**：`stream:true` vs 不传；流式 `for await` 逐 chunk，非流式一次性 `ChatCompletion`
2. **AbortController 在三条路径怎么用**：流式 CLI = 首个 chunk 后 3s；协议 B = 首个 `text` 事件后 3s；HTTP = 首个 `res.write` 后 3s；signal 走 SDK options 第二参
3. **可重试 vs 不可重试分类**：429 / 408 / 5xx / 网络错 退避；400 / 401 / 403 / 404 / 422 不重试
4. **成本估算公式**：`cost = total_tokens / 1000 × MINIMAX_PRICE_PER_1K`；单价 env 化
5. **协议 A vs B 字段差异**：`chat.completions`（OpenAI）vs `messages.create`（Anthropic）；role 位置 / usage 字段名映射；详见 [02-协议-A-vs-B 小节 MD](./02-协议-A-vs-B.md)
6. **SSE 帧格式**：`data: {json}\n\n`，结束帧 `data: [DONE]\n\n`；chunk 是 zod 类实例要 `JSON.parse(JSON.stringify(...))` plain 化
