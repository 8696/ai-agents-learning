## 是什么

「主流模型对比」不是背「今晚谁第一」，而是能列出一张**能查、能换、能估账单**的表。表上至少四家供应商，每家三列：**强项（场景）**、**价格档**、**Context 上限**。过关标准是能列表、知道数字会过期、会去官方页核对——不要求背某一天的精确美元。

比的时候其实是三层标签叠在一起，不能混成一句「ChatGPT 和 Claude 哪个更聪明」：

| 层 | 是什么 | 人话 |
| -- | ------ | ---- |
| **供应商 Vendor** | 谁卖推理 | OpenAI、Anthropic、Google、MiniMax、智谱 |
| **模型族 Family** | 同一家的产品线 | GPT-5 系、Claude Opus/Sonnet/Haiku、Gemini Pro/Flash、MiniMax M 系 |
| **model ID** | 请求体里真正写的字符串 | 如某个 Sonnet 代号、`MiniMax-M2.5` |

前端类比：供应商像云厂商，模型族像产品线，model ID 像真正开通的实例规格。说「我用了阿里云所以一定很快」没有意义——要看开的是哪一档。

**价格档**几乎都写成：每 100 万 Token 多少美元，而且 **Input / Output 分开**。输出通常比输入贵几倍。同一家里永远有几档：旗舰贵而强、主力日常、小模型便宜快。

**Context 上限**是一次请求里输入+输出能共享的长度天花板（已在 Context Window 那条学过）。写进对比表时还要分清：广告数字、价目里的超长溢价档、聊天网页产品的额度，常常不是同一个数。

本仓库学习默认仍是 **MiniMax 协议 A**。本条是为了以后会选，不是现在换供应商。

## 为什么（Agent 开发要懂）

不懂这张表，现在就会踩：

1. **默认旗舰 = 默默烧钱。** Agent 多轮：历史反复当输入送回去，再吐长计划/代码（输出）。输出价常常是输入的 4～6 倍。把「分类意图、抽字段」也打到 Opus / GPT 旗舰上，等于每一次都请专家开会。
2. **窗口不够会静默丢上下文。** 系统提示 + 长文档 + 用户问题超了上限，前面被截或请求失败。表现像「它忘了规则」，根因是长度，不是突然变笨。
3. **强项对不上任务。** 长 PDF / 图视频更吃多模态 + 长窗口；长文和代码 Agent 很多人拿 Claude 主力档；工具调用教程密度 OpenAI 往往最好找。选错不是不能跑，是又贵又容易翻车。
4. **地区和协议不是同一份菜单。** MiniMax 协议 A 是 `openai` SDK + 国内 Base URL。Anthropic 官方是另一套 Key 和价目。「兼容 OpenAI」只是 HTTP 形状像，**价、Context、模型能力不是复制粘贴。** 照海外教程把 `gpt-4o` 填到 MiniMax 上，会失败或跑到完全不同的模型。

对照已学：Token 决定怎么计价；Context Window 决定一次能塞多少；本条决定同一套 Token 规则下该买哪家的哪一档。

## 价格档怎么读（不背数字，懂结构）

人话步骤：

1. 发出去的（系统提示、历史、工具结果）→ **输入价**。
2. 模型吐出来的 → **输出价**，通常更贵。Agent 爱说话，账单往往死在输出。
3. 有的家对超长提示（例如超过 200K）再加一档溢价；有的家提供 **Prompt Cache**：同一大段系统提示反复打，第二次可按更便宜的缓存读取计。
4. **网页订阅**（ChatGPT Plus、Claude Pro）按座/按月，还有时段额度，**不是** API 接口打账单里那种。

**2026-09 量级快照（只为建立档位，以官方页为准）：**

| 档 | 大致量级（输入 / 输出，每 1M Token） | 典型位置 |
| -- | ----------------------------------- | -------- |
| 旗舰 | 约 $5 / $25～$30 | OpenAI 最新旗舰、Claude Opus |
| 主力日常 | 约 $2～$3 / $10～$15 | Claude Sonnet、OpenAI 非旗舰主力 |
| 便宜/快速 | 约 $0.5～$1.25 / 数美元 | Gemini Flash / 部分 Pro、Claude Haiku |
| 国内高性价比 | 约 $0.3 / $1.2 量级 | MiniMax M2.x 文档价（M3 以打开当天价目为准） |

本次能核对到的官方片段：Anthropic API **Opus 5** $5 / $25，**Sonnet 5** $2 / $10，**Haiku 4.5** $1 / $5（每百万 Token）。过关说法：「旗舰大约是主力的两倍以上，MiniMax 比旗舰便宜一个数量级」即可。

## 四家以上：强项 × 价格档 × Context

「强项」是常见用法，不是永恒定律。换任务要重测。

| 家 | 强项（一句） | 价格档 | Context 量级 |
| -- | ------------ | ------ | ------------ |
| **OpenAI** | 生态/工具文档密，综合默认 | 旗舰贵，另有 mini | 可达百万级，看具体 ID 与价档 |
| **Anthropic** | 写、推理、代码 Agent 口碑 | Opus 旗舰 / Sonnet 主力 / Haiku 便宜 | 聊天产品常见 200K；API 看 ID（有宣传 1M 的） |
| **Gemini** | 长文 + 多模态 | 相对美西旗舰便宜；长提示或另计价 | 常比 **1M** |
| **MiniMax** | 国内默认、双协议、性价比 | 远低于美西旗舰 | M2.x **约 205K 合计**；**M3 文档 1M** |
| **智谱 GLM**（建议能点名） | 中文、国内、同样双协议 | 以开放平台当天价目为准 | 出门抄官方页；模块 02 才接到仓库 |

MiniMax 官方模型表（本次核对）：最大 Token 指 **输入+输出合计**。M3 = 1,000,000；M2.7 / M2.5 / M2.1 / M2 = 204,800。

Context 写进表时还要记住：有 1M ≠ 每次该塞 1M（更贵、更慢、噪音一起进去）。价目若写「某长度以下一档价」，窗口也许更大，超长仍可能更贵。聊天页写 200K，不等于你打的那个 API model ID 也是 200K。

### 多档对照（同一家的"主力 / 便宜"档）

「同一家永远有几档」画成表更直观。**数字当档位记，精确值以官方页为准**。

| 家 | 旗舰 | 主力日常 | 便宜 / 快速 |
| -- | ---- | -------- | ----------- |
| **OpenAI** | 当代最强（价格最高） | 主力档（综合默认） | mini / nano |
| **Anthropic** | Opus 5（$5/$25） | Sonnet 5（$2/$10） | Haiku 4.5（$1/$5） |
| **Gemini** | Ultra / Pro 高档 | Pro 主力 | Flash（延迟低） |
| **MiniMax** | M3（1M 窗口，按量档位以官方为准） | M2.5 / M2.7（≈ 205K） | 国内高性价比主力 |
| **智谱 GLM** | glm-4-plus / 4-air | glm-4-flash | glm-4-flash 即便宜档 |

读法：**先看窗口够不够 → 再选同档里最便宜能过验收的那一档**。不到终审不碰旗舰。

### 本仓库当前在用（写代码时直接抄）

`apps/00-环境准备/01-mini-app` 当前主路径（`yarn app:00-01-mini-server` = 协议 A HTTP）实际写进 `.env` 的字符串：

| ---- | ------ | ---- |
| `MINIMAX_BASE_URL` | `https://api.minimaxi.com/v1` | MiniMax 中国区 · 协议 A 入口 |
| `MINIMAX_MODEL` | `MiniMax-M3` | 主路径默认 model ID |
| `MINIMAX_ANTHROPIC_BASE_URL` | `https://api.minimaxi.com/anthropic` | 同 Key，模块 02 启用 |
| `MINIMAX_ANTHROPIC_MODEL` | `MiniMax-M3` | 协议 B 共用同一 model ID |

模板见 [`apps/.env.example`](../../../apps/.env.example)。模块 02 启用时再加：智谱 `glm-4-flash`（A/B 两套端点）、Anthropic 官方 `claude-sonnet-4-20250514`（仅协议 B，海外）。

### 协议 A / B 怎么挂

不是「想挂谁挂谁」——**SDK 形状锁了协议，端点锁了家，model ID 锁了档**。

| 协议 | SDK | Base URL 形态 | 谁提供 |
| ---- | --- | ------------- | ------ |
| **A** OpenAI Chat Completions | `openai` | `/v1` 后缀 | OpenAI 官方 · MiniMax · 智谱 · Gemini OpenAI 兼容端点 |
| **B** Anthropic Messages | `@anthropic-ai/sdk` | `/anthropic` 后缀 | Anthropic 官方 · MiniMax · 智谱（都有 Claude 兼容层） |

要点：

- 同一家（如 MiniMax）**同一把 Key 给两套 Base URL**：协议 A 走 OpenAI 形状，协议 B 走 Anthropic 形状。**账单和限速共享一份 Key**。
- 海外 Anthropic **只支持协议 B**，没有协议 A 端点。
- "兼容 OpenAI / 兼容 Anthropic" 只是 **HTTP 请求体形状像** —— 价、Context、模型能力、工具字段名不复制。
- 跨协议换家：要换 `Base URL + Key + model ID + SDK 引入 + 字段名`。**换家成本远大于换档**。

## 易混点

**能力边界 vs 幻觉 vs Context 上限**  
能力边界：模型族本来就不会的事（精确实时库存、没给工具时的真计算），换更贵旗舰也经常不行。幻觉：下一个 Token 的流畅瞎编。Context 上限：塞不下了，丢了或报错。判错：窗口满了去拧 Temperature；幻觉了去买 1M 窗口；能力边界以为「换 Claude 就有库存 API」。

**「某家全面碾压」vs「按任务选档」**  
排行榜是别人的考卷。中文客服分类用 Haiku / MiniMax / Flash 就可能够。判错：全年锁死旗舰，钱花完了质量只高了一点点。

**网页 Chat 产品 vs 同品牌 API**  
套餐、额度、默认窗口不是 `baseURL + model` 那张价目。判错：用 Plus 月费去估 Agent 打 100 万 Token 要多少。

**排行榜第一 vs 你的延迟/价/地区**  
第一名若只要美国卡、输出极贵，国内课设用不上。判错：照英文博客改 `model`，Key 还是 MiniMax，请求失败。

**Context 写 1M ≠ 每次塞 1M**  
选型列上的上限是天花板，不是目标填充率。判错：整仓代码每轮都贴，「窗口还没满」但账单满了。

**兼容 API ≠ 同一份模型**  
MiniMax / 智谱可以长得像 OpenAI 或 Anthropic 的 HTTP。换的是 Base URL + model ID，不是免费升级成海外旗舰。判错：把海外价和海外评测安到国内 model ID 上。

同一家分词器也不同：同一段中文在 A 家 80 Token、B 家 120，**不能拿一家 tokenizer 估另一家账单**（对照 Token 那条）。Temperature 是「请来之后有多跳」，不能靠拧温度补上长窗口或换错家。预训练 vs 推理：对比的是各家已经训好的**推理产品**，不是你去训 GPT。

**输出上限 vs Context 上限**  
Context = 一次请求**输入 + 输出**合计的天花板（如 200K / 1M）。`max_tokens`（Anthropic 同名、OpenAI 也同名）是**单次输出**的上限——即使 Context 还剩 999K，请求里写 `max_tokens: 1024`，模型也只能吐 1024 个 Token 就停。Agent 长计划 / 长代码被截，常常是忘了 `max_tokens`，不是 Context 满了。

**写错 model ID 时的故障形态（按危险度排）**  
1. **`404 model_not_found`**：明报错，改名即可。最不危险。
2. **`401 / 403 invalid_api_key`**：Key 不对或没权限访问这个 model。先核对 Key、Base URL 是否对应该家。
3. **静默降级 / 路由到别家 model**：最危险。某些兼容层在 model ID 拼错时会**自动落回默认 model**，请求 200、账单照算，但跑的是另一档模型——你以为是 Opus 在回答，其实是 Haiku。判错方法：每次请求后看响应里的 `model` 字段回显，而不是只看 HTTP 200。

## 例子

**供应商 / 模型族 / model ID：** 不能说「我用了阿里云所以一定很快」；要看实例规格。请求里必须写对 model ID，写「Claude」三个字账单系统不认。

**强项（OpenAI）：** 要跟文档抄 `chat.completions` 字段名，网上 GPT 系示例最多——像 React：不一定每个基准第一，但是「搜得到人踩过的坑」。

**强项（Claude）：** 像请编辑改 40 页方案——Sonnet 当主力编辑，Opus 当终审，Haiku 当把会议纪要收成三条的实习生。

**强项（Gemini）：** 一本电子说明书 + 几张截图问「第 12 章和 UI 对不上」——这是长窗口 + 多模态的戏，不是再换一个更会考试的纯文本旗舰就能替代。

**强项（MiniMax）：** 像国内云性价比实例：演示课、练手把链路跑通先用它；对照官方 Claude 行为等到模块 02 再接另一套端点。

**强项（智谱）：** 像第二家国内 CDN：主站 MiniMax，中文评测或灾备再加 GLM；协议长得像，账单和模型名不能混用。

**价格档：** 输入价像上传带宽，输出价像 CDN 回源流量——用户看到的字都是输出。分类意图却请旗舰上门，就是档用错。生活里：修水管先普通师傅（主力），结构改水电才请专家（旗舰）。

**Context 上限：** 行李箱限重 20kg。1M 像货舱能装衣柜，200K 是登机箱。能装不等于该每次装满——安检（延迟）和运费（Token）一起爆。前端：不会因为 `localStorage` 理论上有几 MB 就把整站 CDN 资源塞进去。

**选档流水线：** 像图片：缩略图用便宜档，详情大图才开付费清晰档。Agent 里不是全程一张旗舰卡。

## 取舍

人话流程（本条只建立选型脑子，不写路由代码、不提前讲后面整模块）：

```text
先定任务：短分类 / 写长文 / 啃长 PDF / 写代码 / 要看图
    → 先选「窗口够不够」（约 200K vs 约 1M）
    → 再选「要不要多模态」
    → 再在窗口够的家里选最便宜能过验收的那一档
    → 难题、终审、用户能感知的质量，再升旗舰
    → 地区：本课默认 MiniMax 国内；对照官方 Claude 等到模块 02
```

学习阶段没卡住之前，不要为了对比换掉仓库默认供应商。

**选档例子（与上面流程一一对应）：**

| 任务 | 选档 |
| ---- | ---- |
| 用户消息分类 / 抽字段 / 拼请求参数 | MiniMax 主力 / Claude Haiku / Gemini Flash / glm-4-flash |
| 改一段代码 / 写一封长邮件 / 解释一段长文 | Claude Sonnet / OpenAI 主力 / MiniMax M3 |
| 啃 200 页 PDF + 截图提问 | Gemini Pro / MiniMax M3（窗口优先） |
| Agent 终审打分 / 兜底解题 | Opus / GPT 旗舰（占整体调用的少数） |

实战里更多是**一主一审**：主力跑全链路，便宜档做"路由器"决定哪条送旗舰——这部分留到模块 19（按任务总成本路由）展开。

## 过关自检

- 能不看稿列出至少 4 家：各一句强项、一个价格档（旗舰/主力/便宜即可）、一个 Context 量级（约 200K / 约 1M）。
- 能说清为什么不能只看「谁第一」：任务、价、长度、地区、协议不是同一根尺子。
- 能举一个选错档的后果：例如用旗舰做分类把钱烧光，或把长合同塞进约 200K 窗口被截断。
- 不把「模型笨（能力边界）」「瞎编（幻觉）」「窗口满了（Context）」说成同一件事。
- 数字当档位记，精确报价以打开当天的官方价目 / Model Card / [Artificial Analysis](https://artificialanalysis.ai/) 为准。
