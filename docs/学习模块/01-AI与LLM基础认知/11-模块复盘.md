### 一句话讲完这个模块

理解「**LLM 是个什么东西**」+「**它为什么会做出现有的事**」——AI/ML/DL 的位置、Token/Context/Embedding/Transformer/Attention 五件事各自解决什么问题、为什么会有幻觉、训练和推理各自的边界、主流模型差异在哪。

### 这些条怎么连成一条线

10 条不能并列读，要按「**由内到外、由结构到行为、由原理到选型**」串成一条线：

```text
[01 AI ⊃ ML ⊃ DL]  ── 给 LLM 在学科地图里一个位置
        ↓ 落到「LLM 内部」
[02 Token]  ── 计费单位 / 模型读写最小单元
[03 Context Window]  ── 一次请求长度上限（Token 的容器）
[04 Transformer]  ── 「看整句关系」的架构（Encoder/Decoder + Self-Attention）
[05 Attention]  ── Transformer 真正干活的机制
[06 Embedding]  ── 文本→向量，把「语义近」变成「距离近」
        ↓ 走出结构到「运行时行为」
[07 Temperature / Top-P]  ── 同一模型 / 同一 prompt 也能跑出不同结果
[08 Hallucination]  ── 为什么「流畅但假」是必然产物，不是 bug
[09 预训练 vs 推理]  ── 你调 API 落在哪一段，调 vs 训的边界
[10 主流模型对比]  ── 同能力不同价位 / 上下文长度 / 强项，按任务选型
```

跨条才看得见的关系：

- **02 Token → 03 Context**：「Token 数 × 上下文长度」是费用和截断的同一根尺子。复述 02 不讲「中文更贵」在哪兑现，复述 03 不讲「截断按什么单位截」，两件事一对才完整。
- **04 Transformer + 05 Attention** 是同一件事的两个粒度。04 是「这个模型长这样（三块）」，05 是「中间那块怎么算」。两节分开是因为 04 是骨架能画图，05 是一句话讲得清。
- **06 Embedding 不是 02 Token 的升级版**。Token 是离散计数（输入输出怎么算钱），Embedding 是连续向量（语义怎么度量）。把它们当同一件事是这一刀最常见的错。
- **07 Temp/Top-P 是 09 推理阶段**的参数；预训练阶段不调它。复述 09 不解释「温度」，复述 07 不必提「训练」——但要意识到它们落的是同一段。
- **08 幻觉和 03 Context 不是一回事**：截断是「说不下」，幻觉是「说错」。两者都是「模型做不到的事」，但失败模式不同。
- **10 是 02/03/07 的应用层**：选模型本质是在比较 Token 单价 × Context 上限 × 行为差异（温度响应曲线）。

### 最容易记错的三条

| 易混 | 差在哪 |
| --- | --- |
| **Token vs Embedding** | 一个是离散计数（输入/输出计费、长度上限的度量单位），一个是连续向量（语义远近的度量）。**Token ID 直接查表，Embedding 是高维空间中的点**。把 Embedding 当成「更高级的 Token」是最常见的错 |
| **幻觉 vs Context 截断** | 两者都是「做不到的事」，但失败模式相反——**幻觉是「说了，且说得流畅但假」**；**截断是「没说，超出长度被砍」**。前者要靠检索/工具/约束减少编造，后者要靠摘要/分片/滑动窗口缩短输入 |
| **Temperature vs Top-P** | 一个缩 logits（分布形状），一个截断候选（候选池大小）。**正交，可叠用**，不是二选一。常见错：「温度 0 = 总是同一答案」其实只是把概率集中到 Top-1，不保证 token 序列相同（同一模型不同请求的 sampler 状态可能略有差异） |

| Demo / 入口 | 跑它当时看清了什么 |

### 踩过的坑（跨条）

- **02 Token + 09 预训练**：以为 Token 是训练阶段固定下来的——其实 Token 化（tiktoken）是**推理时的前处理**，跟训练用什么 tokenizer 是同一套东西。两条分开讲才会意识到「模型能读什么」是 tokenizer 决定的，不是模型决定的。
- **04 Transformer + 05 Attention**：以为「Encoder / Decoder」=「读 / 写」——其实是两种「看整句关系」的方向。Decoder-only（GPT 系）现在是大头，不是「阉割版 Transformer」。
- **06 Embedding + 02 Token**：把 Embedding 当「Token 的高维表示」——其实 Embedding 是**模型学出来的**，不是查表来的；同一个 token 在不同模型里 Embedding 不同。
- **07 Temperature + 10 模型对比**：以为「温度 0 = 确定性输出」=「正确答案」——温度 0 只决定采样策略，模型本身在不确定的题上还是会错。模型选型决定上限，温度只决定「在上限附近的方差」。
- **08 幻觉 + 03 Context**：把幻觉归因成「上下文太长分心」——其实幻觉跟长度关系不大，跟**训练数据稀疏 / prompt 引导歧义**关系更大；短的 prompt 也会编。
- **09 预训练 vs 推理 + 07 Temperature**：以为「调温度 = 改模型」——温度只是推理阶段的采样参数，不改模型权重；任何「调温度使模型变好」都是采样层面的，不是模型层面。
- **10 模型对比 + 02/03**：以为「Context 越大越好」——Context 大通常单价更贵 + 注意力稀疏度上升；选型要算「单次任务总 Token × 单价」，不是单看窗口数字。
