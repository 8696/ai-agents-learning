## 给非技术朋友的「LLM 为什么会胡说八道」

如果你只想带走一句话，就这一句：

> **大模型是个超级会接话的演员。它不是"在回答你的问题"，它是在"猜下一句最像人话的话该是什么"。所以它能讲得头头是道，但内容不一定是真的。**

把它当 IDE 的自动补全开到极致：你写「亲爱的」，它给你补「张老师，」；你写「您好」，它给你补「关于上次会议的纪要，」。补出来的句子**通顺、语气对、措辞像你**——但补的是不是事实，它不查，也查不了。

把它当一群人接龙编故事：第一个人说"从前有只狐狸"，下一个人接"它有三条尾巴"，再下一个接"它的邻居是奥巴马"。**没人去查奥巴马是不是狐狸的邻居**——大家只关心接得通不通。LLM 也是这样，它只关心接得通，不关心是不是真的。

把它当一个接到剧本的演员：剧本说"扮演一个物理学家，解释量子纠缠"。演员没学过物理，但能讲得自信、术语堆得对、语气像专家——**但内容可能是错的**。

它编的时候还**特别自信**——因为它的训练目标就是"下一句接得越像真话越好"，没人告诉它"接不上就别接"。**这就是幻觉（hallucination）**——表面顺、内在错、还打包票。

为什么它默认就会这样？因为它**没有事实核查这一步**，**没有"我不知道"按钮**。你说"我没说"，是修这个的开关，但 LLM 没装这个开关，它只能硬编一个听起来最像的。

## 给前端自己的「为什么我也跟着踩」

把上面那条落到我们日常写代码会踩到的四件事上：

| 翻车 | 表面 | 根因 | 修法 |
| ---- | ---- | ---- | ---- |
| **Token 烧钱比预期多** | 用 GPT / Claude 旗舰跑分类，账单远超预估 | 模型按"打包件（Token）"计费，输出更贵；中文常被切得更碎（贵在数量，不是单价溢价） | 任务分层：分类/抽字段用便宜档（Haiku / Flash / MiniMax 主力），只有终审/兜底才升旗舰 |
| **"它忘了规则"** | Agent 突然不按系统提示走了 | Context Window 有上限——超出就截断或失败，**不是"变笨"** | 关键规则放系统提示最前面；超长文档先摘要再塞；监控当前 Context 余量 |
| **温度调低了还是幻觉** | 把 Temperature 调到 0 还是编论文、编 API | 温度控的是"接得多花"，不是"事实对不对"——幻觉与 Temperature 无关 | 上 RAG / Tool Calling / Structured Output，让"不知道"成为合法答案（模块 02 / 05 展开） |
| **默认旗舰跑全链路** | 一个 Agent 全程 Opus / GPT 旗舰 | Agent 多轮：每步 reasoning + tool call 都计输出，输出是输入的 3–5× | 一主一审：主力档跑全链路，便宜档做路由器；少数终审才升旗舰（模块 19 展开按任务总成本路由） |

**一句话**：写 Agent 不是"挑一个最聪明的模型"，是"按任务挑一档档、按步算 Token 账"。

## 机制串讲（按 1–10 的顺序把一条主线拉通）

把模块 01 十条串成一条「为什么 LLM 是这样、为什么它是这样翻车」的机制线。**不推公式，只讲步骤**。

**第一步（01）：AI ⊃ ML ⊃ DL ⊃ 神经网络**——三者不是并列名词，是包含关系。AI 是大筐，ML 是筐里的"用数据学规律"，DL 是 ML 里"用深度神经网络学"，神经网络是 DL 里"用很多层参数拟合输入→输出"的工具。**LLM 是一种深度神经网络**。把它想成"一个巨大的、参数极多的函数 f(x) = y"——给它一段字（x），吐下一句（y）。它的训练就是用海量文本去"调"这些参数，让吐出来越来越像人话。

**第二步（02）：LLM 读写的是 Token，不是字**——人看到的是「你好世界」，模型看到的是 `[1523, 88, ...]` 这样的整数 ID。Tokenizer 是把字切块、查表的程序。计费按"打包件数（Token）"算，不是按"字数"。中文常被切得更碎，所以同样意思 Token 更多，**更贵**。中文字符的 Token 密度大约是英文的 5–6 倍（实测见 [02-Token.md#例子](./02-Token.md#例子)）。输出比输入贵 3–5×，因为吐每一个 Token 都要重做一次完整前向。

**第三步（03）：Context Window 是序列长度的硬约束**——一次请求里输入+输出共享一个长度上限。常用 200K（聊天产品常见），有的能到 1M。**超了就截断或失败，不是"忘了"。** Agent 多轮：每一步的历史都当输入塞回去，几轮下来很容易撞上限。

**第四步（04–05）：Encoder-Decoder 是骨架，Self-Attention 是眼睛**——Transformer 把"一段 Token 序列"读进来、编成内部表示、再吐下一段。Self-Attention 让每个 Token 在编码时"看一遍整句其他 Token"，算它们对我的权重——相当于读句子时不断回头看"这个词和那个词什么关系"。这就是为什么 LLM 能学"它"指代谁、长程依赖怎么搭。**前端类比**：组件 render 时 props 会拿到祖先传下来的所有 context——Self-Attention 像 render 时同时拿到全序列的上下文。

**第五步（06）：Embedding 是把 Token 拆成"语义坐标"**——Token 是离散编号（id 1523），Embedding 是连续向量（[0.12, -0.87, 0.34, ...]）。**语义近的句子，向量距离近**。这是 RAG / 搜索 / 推荐系统的地基。**和 Token 不是同一层**——Token 管"切块 + 计数"，Embedding 管"语义远近"。

**第六步（07）：Temperature / Top-P 控的是"接得多花"**——模型每次是从一个概率分布里采样下一个 Token。Temperature 把分布"压扁/拉平"（低 = 更确定，高 = 更花）；Top-P 在分布里只保留概率累计到 P 的头部候选，再从候选里抽。**抽取任务（分类/抽字段）→ 低温度；创意任务（写故事/起标题）→ 较高温度。** 调温度不治幻觉（见第八步）。

**第七步（08）：幻觉是这条机制的副产品，不是 bug**——训练目标是"下一个 Token 像不像真的"，没人教它"别编"。它没有事实数据库，没有"我不知道"按钮，没有"我去查一下"的回路。所以它**形式对（标题/作者/年份对）、事实错（搜不到那篇论文）、还特别自信**。5 种典型形态：编造引用、编造人物、虚构数据、混淆相似概念、时间穿越。**蒙对也是幻觉**——你看到对的没感觉它编了多少次才蒙到一次。

**第八步（09）：预训练 vs 推理**——**训练你不做**。你调 API 做的是**推理**：模型已经被几千万到几亿美元砸出来训好了，你每次请求只是"把参数当函数跑一遍"。RLHF（人类反馈强化学习）是训练阶段后期一道工序，让它更"像你想要的样子"——这一步也不归你做。**前端类比**：你用 React 不会自己写编译器；用 LLM 不会自己训模型。**选档 ≠ 训练**。

**第九步（10）：各家的模型各走这条机制**——OpenAI / Anthropic / Gemini / MiniMax / 智谱 都在做同一件事（下一个 Token 预测器），但实现 / 词表 / 训练数据 / 价格档 / Context 上限 / 多模态支持不一样。**本仓库学习默认仍是 MiniMax 协议 A**（`openai` SDK + 国内 Base URL）；对照官方 Claude 等到模块 02 接另一套端点。选型不是"谁第一买谁"，是按任务挑"窗口够不够 / 要不要多模态 / 同档里最便宜能过验收的那一档"。

**这条主线一句话**：LLM 是一个**用海量参数拟合"下一个 Token 是什么"的超级函数**，它只会接话不会查证，所以默认就会编；写 Agent 不是挑一个最聪明的，是按任务挑档 + 按步算 Token 账 + 给它检索/工具/结构化输出，让"不知道"成为合法出口。

## 通俗例子串讲（每个核心对象 ≥1 个非技术例子）

模块 01 的"核心对象"：AI/ML/DL 关系、神经网络、Token、Context Window、Embedding、Transformer / Self-Attention、Temperature / Top-P、幻觉、预训练 vs 推理、主流模型对比。每个已在 1–10 给过非技术例子；这里把它们串成"一条龙"：

**例子：让 LLM 帮你写一封道歉信给张老师，因上周缺课。**

- **AI ⊃ ML ⊃ DL ⊃ 神经网络**：你拿到的是一个"很多参数的函数"——丢进去"道歉 + 张老师 + 缺课"，吐出来一段话。**没人告诉你它为什么这么写**，因为它是拟合出来的。
- **Tokenizer 先动手**：你写的「张老师，上周缺课很抱歉」被切成几十个 Token；输出几十个 Token 也要钱。中文 Token 密度比英文高，账就贵一点。
- **Context Window 算长度**：你这封信 + 历史 + 系统提示 = 一次请求的总长。超了就截断。**它不会"忘了规则"**，只是窗口不够。
- **Embedding 在语义层**：模型内部把"道歉"、"缺课"、"张老师"这些 Token 映射成向量，"老师"和"学生"在向量空间里离得近，所以它能写出合适的语气。
- **Self-Attention 在算关系**：写到"很抱歉"时回头看"张老师"，写到"缺课"时回头看"上周"，决定主语、用词、语气。
- **Temperature 在采样**：温度低就稳稳地"非常抱歉由于上周未能出席课程"，温度高就"这两天翻来覆去想给您道个歉，我上周缺了课心里一直过不去"。
- **幻觉在这条线上：如果你没说"张老师教什么课、为什么缺课"，模型会**编**一个看起来对的版本**——"因家中临时有事"——编得通顺、自信、但你没说就是没说。
- **预训练 vs 推理**：你没训它，你只是调 API 让它把已经训好的参数跑一遍。
- **主流模型对比**：你用 MiniMax 协议 A（国内便宜档）跑这封信，再选 Sonnet 终审改一改措辞，账单比全程 Opus 低一个数量级。

**这条链把 10 个核心对象串成一个故事**：你不是学了 10 个孤立名词，是知道它们怎么把"输入一段话"变成"输出一段编出来的、但接得通的人话"。

## 取舍（本条不写代码，但写"用 Agent 的取舍"）

| 取舍 | 选 A | 选 B |
| ---- | ---- | ---- |
| **处理幻觉** | 改 prompt："请不要编造"（没用，模型没装这个开关） | 上 RAG / Tool Calling / Structured Output（让"不知道"成为合法答案） |
| **Context 不够** | 把整仓代码每轮贴回去 | 摘要 / 滑动窗口 / RAG（按需检索） |
| **Temperature 选档** | 默认 0.7 通吃 | 抽取任务低温度（0–0.3），创意任务中高（0.7–1.0） |
| **模型选档** | 全程旗舰（账单爆炸，质量只高一点） | 一主一审：主力档跑全链路，便宜档做路由器，少数终审升旗舰 |
| **Tokenizer 选错** | 用 OpenAI tiktoken 估 MiniMax 账单 | 各模型按 model 名选对应 tokenizer；对账只信 `usage` |
| **要不要锁 Temperature / Seed** | 不锁，输出每次都飘 | 生产里锁（保证可复现 / 可评测） |

**一句话取舍**：写 Agent 的所有决策，本质都是"在 Token 预算 × 任务复杂度 × 幻觉风险"这三个旋钮之间找位置。

## 过关自检（覆盖 README 验收 7 条，对照说人话）

1. **AI ⊃ ML ⊃ DL ⊃ 神经网络** → AI 是大筐，ML 是"用数据学规律"，DL 是 ML 里"用深度神经网络学"。神经网络是"用很多参数拟合输入→输出"的工具。**LLM 是一种深度神经网络**。
2. **3 件当前 LLM 做不好的事 vs 幻觉 vs Context 上限** → 能力边界（架构就不会：精确大数算术、私有库查不到、实时实时事件）≠ 幻觉（接得像人话但事实错）≠ Context 上限（塞不下了，截断或失败）。**判错会怎样**：窗口满了去拧温度；幻觉了去买 1M 窗口；能力边界以为换 Claude 就有库存 API。
3. **Token / Context / Embedding / Transformer / Attention 各自解决什么问题** → Token：把字切成可计数的块；Context：一次请求里输入+输出共享的天花板；Embedding：把语义映射成向量（语义近距离近）；Transformer：处理序列的骨架（Encoder-Decoder）；Self-Attention：每个 Token 回头看整句其他 Token，算权重。
4. **Temperature / Top-P 区别 + 场景** → Temperature 控分布"压扁/拉平"；Top-P 在分布头部按累计概率保留候选再抽。**抽取任务（分类/抽字段）→ 低温度；创意任务 → 中高温度**。
5. **幻觉一句话** → 模型在"预测下一个 Token"，不在"查数据库"——它没有事实核查这一步，所以会编，编的时候语气还特别自信。
6. **4 个主流模型 + 强项 + 价格档** → OpenAI（生态/工具文档密）、Anthropic（写、推理、代码 Agent 口碑）、Gemini（长文 + 多模态）、MiniMax（国内默认、双协议、性价比）。每家都有"旗舰 / 主力日常 / 便宜快速"三档。
7. **tokenizer 实操过一段中英文** → 同一段意思：中文 14 字→17 Token vs 英文 58 字→15 Token（cl100k_base）。中文字符 Token 密度约 5–6×英文。**中文通常更贵，贵在数量，不是单价溢价**。
