### 一句话讲完这个模块

把 Agent 从「本地能跑」推到「线上别人能访问」——三件事一起做：流式响应不被网关缓冲（SSE 三件套）、长任务不占死 HTTP（任务队列）、文件不进 DB 大字段（对象存储 + RBAC）。**部署环节必须真做一次**——本地跑得好不等于生产没问题。

### 这些条怎么连成一条线

本模块三条外部小节不是平行清单，而是**三道边界防线**，每道防一层防一个具体的部署边界：

```
        ┌─────────────────────────────────────────────┐
        │        用户浏览器 / 外部客户端                │
        └──────────────────────┬──────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 响应层（边界：HTTP 请求 / 浏览器）                           │
│ 01 SSE 被网关缓冲：Nginx / CDN / PaaS 关 buffer + 长 timeout│
│ → 流式「边到边」不被攒满再喷                                │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 异步层（边界：HTTP 请求的时间）                              │
│ 02 任务队列：长任务异步化 + 状态机 + 幂等 + DLQ               │
│ → 5 分钟任务不占死 HTTP / 客户端不被超时切断                │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 资源层 + 权限层（边界：数据 / 多租户）                       │
│ 03 对象存储 + RBAC：大文件落对象存储 + 用户鉴权 + 角色权限  │
│ → 100MB PDF 不进 DB；普通用户不能退款                       │
└──────────────────────────────────────────────────────────────┘
```

- **响应层**：管**HTTP 请求的生命周期**——浏览器发请求，服务端返回响应（流式响应要跨 Nginx / CDN / PaaS）
- **异步层**：管**任务的生命周期**——客户端提交 → 队列执行 → 异步拿结果（长任务必须异步化）
- **资源层 + 权限层**：管**数据 + 多租户**——文件落哪、谁能调什么（防止 DB 撑爆 / 权限失守）

三者的关系是**从上到下贯穿**——响应层管外部 HTTP 边界；异步层管任务时间边界；资源层 + 权限层管数据 + 用户边界。**任何一层失守，Agent 上线就崩**。

### 最容易记错的三条

1. **`proxy_buffering off` ≠ `proxy_cache off`**——前者关**响应缓冲**（流式生效的关键）；后者关**缓存**（响应缓存）。把两者搞混 → 配了 `proxy_cache off` 但没配 `proxy_buffering off` → **流式仍然「卡住再喷」**。
2. **任务队列 ≠ 流式输出（SSE）**——30 秒任务用 SSE 流式（用户看着字出来）；10 分钟任务用任务队列（立刻返回 task_id + 异步查进度）。两者**不互换**——30 秒任务用队列是过度投入；10 分钟任务用 SSE 是 HTTP 早就断了。
3. **对象存储 ≠ 文件系统**——对象存储走 **HTTP RESTful API**（`PUT /objects/xxx`）；文件系统走 **OS API**（`open` / `read`），需要 `mount`。把对象存储当文件系统用 → 不能挂载 / 不能像本地文件一样操作 → 必须在代码里走 HTTP。

### 踩过的坑（跨小节）

写到这里，本对话未踩到具体代码坑（无 Demo 落地）。记录两条**预防性踩坑**：

- **「关错开关」= 流式仍然卡**：配 Nginx 时只关 `proxy_cache off`（缓存），没关 `proxy_buffering off`（缓冲）→ 流式仍然「卡住再喷」。**判错代价**：上线后用户等 30 秒看不到一个字。模块 01「易混点 · proxy_buffering off vs proxy_cache off」专门拉出一组对比；做真实项目时配完 Nginx 后用 `curl -N` 验证首 token 时间。
- **「60 秒掐表」= 长任务中途断**：Nginx `proxy_read_timeout` 默认 60s，LLM 写代码任务跑了 90 秒 → 第 61 秒断流 → 用户看到一半结果。**判错代价**：长任务永远显示不全。模块 01「核心概念 8 长连接超时」专门拉出一节；做真实项目时把所有 timeout（`proxy_read_timeout` / `proxy_send_timeout` / `keepalive_timeout`）都调到 3600s+。
