`01-API-Key-计费` 钉「钱怎么扣、Key 怎么分」→ `02-Node-22` 钉「机器怎么对齐、不被旧版本绊倒」→ `03-密钥安全` 钉「Key 怎么放、泄露了第一时间干什么」→ 三条汇成 mini-app HTTP + `01-API-Key-计费` Demo：**能发、能流、能看见 usage、Key 不进 git**。复盘这条线不展开按条内容，只点出跨条才成立的几件事：

### 最容易记错的三条

跨条放一起才容易混，单看一条不容易翻车：

| 易混 | 真相 |
|------|------|
| 「网页能聊天 = 代码能调 API」 | 会员 Key（ChatGPT Plus / Token Plan 一类，给网页产品用）≠ 按量 API Key（控制台里的「接口密钥」，给代码调 HTTP 用）。把月卡号填进电表接口会 401，不是 SDK 写错。 |
| `engines: ">=22"` 就是「必须正好 22」 | 它只拦**低于 22**；22 / 23 / 24 都过。`.nvmrc` 写的 22 是**推荐值**，不是唯一合法 patch。锁死 `22.14.0` 才是。换机器在仓库根跑 `nvm use` 也读不到（`.nvmrc` 在 `apps/`）。 |
| 改了 `.gitignore` / `git rm --cached` 就安全了 | 已经 push 上去的历史里 Key 还有效，GitHub Secret Scanning 一类机器人仍能扫走。第一件事是 **rotate**（控制台作废旧 + 重新发），必要时再清历史。`.gitignore` 只是「以后别再拍」。 |

### 踩过的坑（跨条）

按条 MD 里各自列过，这里只放**横跨两条以上才会触发**的坑：

- **版本错觉 → Key 错觉**。`engines` 报错时去改 `MINIMAX_API_KEY` / `baseURL`，是走错科室。先 `node -v`，再在 `apps/` 下 `nvm use`（读 `apps/.nvmrc`），最后才查模型。（`02` + `01`）
- **订阅 Key 错觉 → SDK 错觉**。把 Token Plan 订阅 Key 填进 `MINIMAX_API_KEY`，收到 401 去查 SDK / 网络。其实是「月卡插电表」。控制台 → 接口密钥 / 按量 Key。（`01` + `03`）
- **域名错觉 → 账单对不上**。`baseURL` 写成 `api.minimax.io`（海外站），国内控制台的账对不上，或请求直接失败。本仓库默认国内 `https://api.minimaxi.com/v1`。（`01` + `03`）
- **.env 散落 → 漏配 / 漏提交**。各小节 Demo 自己放一份 `.env`，总有一间忘关灯、会把纸条贴出去。整份 `apps/` 共用一份 `apps/.env`，各 Demo **复制** `load-root-env.ts`（约 20 行），不抽共享 npm 包。（`03` + mini-app）
- **`process.cwd()` 找 `.env` 找不到**。`yarn app:...` 时 cwd 常常是 `apps/` 或子文件夹，从 cwd 往上走找不到 `apps/.env`。`load-root-env.ts` 用 `import.meta.url` 反推——无论从仓库根、`apps/`、还是子文件夹启动，家都在原处。（`03` + mini-app）
- **改了 `.gitignore` 不 rotate**。已经 push 上去了，扫描机器人几分钟内就把 Key 拆走去刷额度。第一件事 rotate，必要时再清历史。（`03`，跨条最深的一条）
- **Zod 没守门 → MiniMax 401 才反应**。Key 空着不去验，等 MiniMax 401 才报错，排了网络、排了 SDK 才绕回来。Zod 在启动期 `parse(process.env)`，中文报错，立刻停。（`03` + mini-app）
