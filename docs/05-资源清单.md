## 5.3 阅读建议

- **优先读官方文档，其次读源码，最后才读教程文章。** 这个领域变化太快，半年前的博客可能已经过时。
- **看到「某某框架新版本发布」的新闻不要立刻去学**，先问自己：它解决了我现在遇到的什么问题？没有答案就跳过。
- **值得长期关注的一手信息源**：
  - [OpenAI Cookbook](https://github.com/openai/openai-cookbook)、[Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook)
  - 各框架 changelog
  - 论文读摘要和方法即可：[ReAct](https://arxiv.org/abs/2210.03629)、[Toolformer](https://arxiv.org/abs/2302.04761)、[RAG](https://arxiv.org/abs/2005.11401)

**给 AI 助手的提示**：如果我问到某个具体框架的 API 细节，请提醒我去查最新官方文档，不要凭记忆给可能过时的写法。学习阶段默认选型见 [怎么用 1.2](./02-怎么用.md)。
